# Christmas Lights — анимированная декорация аватара

Версия **1.0.0** · утверждена владельцем 30.10.2026 · TGS не экспортирован (см. `STATUS.md`).

Гирлянда из шести лампочек висит над верхней частью круглого фото, как на референсе владельца. Лампочки по очереди загораются и гаснут, мягко покачиваются, у горящих лампочек мерцают блики-звёздочки. Декорация рисует только гирлянду, на прозрачном фоне; фото кладёт под неё ваша страница.

- Холст 512 × 512 (`viewBox="0 0 512 512"`), как у других декораций; масштабируется целиком. Свечение крайних лампочек может чуть выходить за холст (`overflow="visible"`), как на референсе.
- Бесконечный цикл 3 с (180 кадров, 60 fps), без скачка на границе.
- Зависимостей при работе нет, векторы встроены в модуль. Самостоятельный компонент: не требует других декораций.

## Подключение

```html
<div class="avatar" style="position:relative; width:128px; height:128px">
  <img src="photo.jpg" alt=""
       style="position:absolute; left:7.42%; top:7.42%; width:85.16%; height:85.16%;
              border-radius:50%; object-fit:cover">
  <div id="decoration" style="position:absolute; inset:0"></div>
</div>

<script type="module">
  import { mountChristmasLights } from './dist/index.js';
  mountChristmasLights(document.getElementById('decoration'), { size: '100%' });
</script>
```

Место для фото — `AVATAR_AREA`: центр (256, 256), радиус 218, как у остальных декораций.

## Программный интерфейс

Тот же набор, что у других декораций библиотеки: `mountChristmasLights(контейнер, { size, visible, autoplay, speed, className })` → объект с `setSize`, `show`/`hide`, `play`/`pause`/`isPlaying`, `seek(кадр 0–179)`/`frame`/`progress`, `setSpeed`, `destroy`, `element`. Статичная разметка без браузера — `renderChristmasLightsSvg(префикс?, доля?)`. Для разработчиков: `garlandFrame(доля)` — все атрибуты рисунка в любой момент.

## Векторы

| Файл | Состояние |
|---|---|
| `lights_1` (`1.svg`) | горят голубая, розовая, красная (со звёздочками) |
| `lights_2` (`2.svg`) | горят фиолетовая, зелёная, жёлтая (со звёздочками) |

Оба файла встроены байт в байт и не перерисованы. Их элементы сопоставлены один к одному (`component/garlandModel.ts`, тест проверяет):

- рисунок 2 — это рисунок 1, экспортированный с другой рамкой: после сдвига провод и подвесы совпадают, у петли провода есть отличие до 4 единиц — это «дыхание» провода;
- каждая часть каждой лампочки (колба, обводка, цоколь, блики) на рисунке 2 — та же фигура, что на рисунке 1, только повёрнутая (ошибка подгонки < 0,01). Поэтому лампочка рисуется один раз и поворачивается от угла рисунка 1 к углу рисунка 2 — она не раздваивается;
- свечение: включённое и выключенное свечение из двух рисунков плавно сменяют друг друга, внутренний блик меняет яркость (0,6 у выключенной, 1 у горящей), цвета — как в файлах;
- белые блики на проводе в двух рисунках стоят в разных местах — они плавно сменяются;
- звёздочки — свои у каждой горящей лампочки, взяты из файлов.

Положение и форма всех частей совпадают с оригиналами (сравнение по пикселям без покачивания и мерцания: 0,000 и 0,015 из 255).

## Движение

Всё считается из одного числа — прогресса цикла 0…1 (`component/motion.ts`). Все кривые непрерывные, без остановок, и скорость в конце цикла равна скорости в начале — повтор незаметен.

- **Смена состояний («дыхание»):** непрерывная волна (1 − cos 2πp) / 2 — рисунок 1 около 0 с, рисунок 2 около 1,5 с, снова рисунок 1 к 3 с. Гирлянда не замирает: она лишь на мгновение замедляется в самих рисунках, меняя направление. Лампочки идут волной слева направо с небольшой задержкой; провод «дышит» той же волной.
- **Свет:** горящие и выключенные лампочки выглядят как в исходных рисунках. Цветной ореол горящих лампочек мягко «дышит» в общем ритме света (±12 %, 3 волны за цикл). При смене состояния свет плавно нарастает и затухает вслед за поворотом лампочки.
- **Покачивание:** каждая лампочка ±1,6° по синусоиде вокруг конца своего подвеса, соседние со сдвигом по фазе.
- **Звёздочки — блики горящих лампочек:** оригинальной формы, на своём месте, без поворота и перемещения. Все блики одного состояния живут вместе, без задержек: проявляются по мере того, как загораются их лампочки, мягко мерцают в общем ритме света (яркость ±18 %, размер ±5 % вокруг центра звёздочки) и затухают, когда лампочки гаснут.

Форма и положение каждой лампочки в свой момент (около 0 с и 1,5 с, с задержкой волны) совпадают с оригинальным рисунком.
