# Halloween Pumpkin — анимированная декорация аватара

Версия **1.0.0** · веб-компонент утверждён · TGS не экспортирован (см. `STATUS.md`).

Декорация рисуется поверх круглой фотографии профиля, по принципу декораций аватара Discord. Она рисует только себя, на прозрачном фоне; фото кладёт под неё ваша страница.

- Холст 512 × 512 (`viewBox="0 0 512 512"`), масштабируется целиком до любого размера.
- Бесконечный цикл 3 с, 60 fps, без скачка на границе.
- Не зависит от фреймворков: обычный JavaScript-модуль, подходит для любого сайта, React, Vue и т. д.
- Зависимостей при работе нет. Векторы встроены в модуль.

## Быстрый старт

Готовый модуль — `dist/index.js` (типы — `dist/index.d.ts`). Скопируйте папку `dist/` в проект или установите комплект как пакет (`npm install ./halloween-pumpkin`), затем:

```html
<div class="avatar" style="position:relative; width:128px; height:128px">
  <img src="photo.jpg" alt=""
       style="position:absolute; left:7.42%; top:7.42%; width:85.16%; height:85.16%;
              border-radius:50%; object-fit:cover">
  <div id="decoration" style="position:absolute; inset:0"></div>
</div>

<script type="module">
  import { mountHalloweenPumpkin } from './dist/index.js';
  mountHalloweenPumpkin(document.getElementById('decoration'), { size: '100%' });
</script>
```

### Место для фотографии

`AVATAR_AREA` = центр (256, 256), радиус 218 в координатах холста 512. То есть круглое фото занимает **85,16 %** ширины декорации и стоит по центру (отступ **7,42 %** слева и сверху). Декорация не перехватывает клики (`pointer-events: none`).

### React (без отдельной зависимости)

```tsx
import { useEffect, useRef } from 'react';
import { mountHalloweenPumpkin } from '@avatar-decorations/halloween-pumpkin';

export function PumpkinDecoration({ size = 128 }: { size?: number }) {
  const ref = useRef<HTMLDivElement>(null);
  useEffect(() => {
    const deco = mountHalloweenPumpkin(ref.current!, { size });
    return () => deco.destroy();
  }, [size]);
  return <div ref={ref} style={{ position: 'absolute', inset: 0 }} />;
}
```

## Программный интерфейс

| Что | Описание |
|---|---|
| `mountHalloweenPumpkin(контейнер, параметры?)` | Вставляет декорацию в элемент и возвращает её объект |
| параметр `size` | Число = пиксели, строка = любая CSS-длина. По умолчанию `'100%'` |
| параметр `visible` | Показать сразу. По умолчанию `true` |
| параметр `autoplay` | Начать анимацию сразу. По умолчанию `true` |
| параметр `className` | Класс для корневого `<svg>` |
| `.setSize(size)` | Изменить размер; композиция масштабируется целиком |
| `.show()` / `.hide()` | Показать / скрыть |
| `.play()` / `.pause()` / `.isPlaying` | Анимация |
| `.seek(кадр)` / `.frame` | Показать конкретный кадр цикла 0–179 (например, для обложки) |
| `.setSpeed(x)` | Скорость: 1 — обычная, 0.25 — замедление |
| `.destroy()` | Остановить и удалить |
| `.element` | Корневой `<svg>` |
| `renderHalloweenPumpkinSvg(префикс?)` | Статичная разметка SVG строкой, без браузера (сервер, превью) |
| `AVATAR_AREA`, `CANVAS_SIZE`, `FPS`, `FRAME_COUNT`, `LOOP_DURATION_MS` | Константы |
| `HALLOWEEN_PUMPKIN_META` | `id`, название, версия, статусы веб и TGS |

На одной странице можно разместить сколько угодно копий: у каждой свои уникальные `id`.

## Анимация

| Элемент | Движение | Когда |
|---|---|---|
| `pumpkin` | дыхание вокруг низа: высота +2,6 %, ширина +1,6 %; задняя часть стебля неподвижна (стык с `plant`) | вдох 0–1,1 с, выдох до 3 с |
| Глаза | моргание «к брови»: глаз и глазница сжимаются к сердитой линии брови | 1,10–1,70 с |
| `mini pumpkin` | дыхание: высота +4 %, ширина +2,4 % | пик на 1,5 с |
| `tail` | качание ±6° вокруг основания, вместе с дыханием шапочки | 1 качание за цикл |
| `leaf_1`, `leaf_2` | качание ±3,5° и ±3° вокруг оснований; второй отстаёт на 0,25 с | 2 качания за цикл |
| `plant` | изгиб кончика ±3,5°, основание неподвижно | 1 качание за цикл |
| Мышь 1 | проявление, полёт вверх-влево, растворение; крылья ±16° | видна 0,5–2,2 с, 3 взмаха/с |
| Мышь 2 | то же, позже и ниже; крылья ±14° | видна 0,77–2,47 с, 3,3 взмаха/с |

Используются только операции, которые есть в Lottie/TGS: сдвиг, поворот, масштаб и прозрачность группы вокруг опорной точки, морфинг контура с тем же числом точек.

│   │   ├── index.ts          публичный интерфейс

Подключать исходники напрямую тоже можно (`src/decorations/halloween-pumpkin/index.ts`): специальных настроек сборщика они не требуют.

## Пересборка и проверка

Нужен Node.js 18+.

```bash
npm install      # esbuild и TypeScript, только для разработки
npm run build    # встраивает SVG и собирает dist/
npm test         # автотесты
```

Тесты проверяют: цикл без скачка; отсутствие серого круга, фона и элементов интерфейса в декорации; отсутствие конфликтов `id` между копиями; что 9 SVG побайтно совпадают с утверждёнными; что утверждённые композиция и ключевые кадры не изменились; версию 1.0.0 и статус TGS.

Если меняется исходный `.svg`, `npm run build` пересоздаёт `assets/sources.generated.ts`; вручную этот файл не правят.
