# Cat Ears — анимированная декорация аватара

Версия **1.1.0** · утверждена владельцем 30.10.2026 (предыдущая 1.0.0 доступна в `releases/cat-ears/1.0.0/`) · TGS не экспортирован (см. `STATUS.md`).

Два кошачьих ушка над круглой фотографией профиля: светлая внешняя часть, нежно-розовая внутренняя, лавандовая обводка и мех. Кончики ушек живо шевелятся, как у кошки, которая прислушивается. Декорация рисует только ушки, на прозрачном фоне; фото кладёт под неё ваша страница.

- Холст 512 × 512 (`viewBox="0 0 512 512"`), как у других декораций; масштабируется целиком.
- Бесконечный цикл 3 с (180 кадров, 60 fps), без скачка на границе.
- Зависимостей при работе нет, вектор встроен в модуль. Самостоятельный компонент: не требует других декораций.

## Подключение

Готовый модуль — `dist/index.js` (типы — `dist/index.d.ts`). Скопируйте папку `dist/` в проект или установите комплект как пакет (`npm install ./cat-ears`), затем:

```html
<div class="avatar" style="position:relative; width:128px; height:128px">
  <img src="photo.jpg" alt=""
       style="position:absolute; left:7.42%; top:7.42%; width:85.16%; height:85.16%;
              border-radius:50%; object-fit:cover">
  <div id="decoration" style="position:absolute; inset:0"></div>
</div>

<script type="module">
  import { mountCatEars } from './dist/index.js';
  mountCatEars(document.getElementById('decoration'), { size: '100%' });
</script>
```

Место для фото — `AVATAR_AREA`: центр (256, 256), радиус 218 (85,16 % ширины, отступ 7,42 %), как у Halloween Pumpkin и Ghost Orbit.

## Программный интерфейс

Тот же набор, что у других декораций библиотеки: `mountCatEars(контейнер, { size, visible, autoplay, speed, className })` → объект с `setSize`, `show`/`hide`, `play`/`pause`/`isPlaying`, `seek(кадр 0–179)`/`frame`/`progress`, `setSpeed`, `destroy`, `element`. Статичная разметка без браузера — `renderCatEarsSvg(префикс?, доля?)`. Константы `AVATAR_AREA`, `CANVAS_SIZE`, `FPS`, `FRAME_COUNT`, `LOOP_DURATION_MS`, сведения — `CAT_EARS_META`.

## Анимация (1.1.0)

Ушко изгибается двумя слоями движения — мягким покачиванием всего ушка и более живым шевелением кончика: основание стоит на месте (на фото), а чем выше точка ушка, тем сильнее она поворачивается вокруг середины основания. Так шевелятся верхняя часть и кончик. Изгиб одинаково применяется ко всем частям ушка — светлой части, розовой внутренней, обводке, меху и градиентам, — поэтому розовая часть движется вместе с контуром и ушко сохраняет свою форму.

| Что | Движение |
|---|---|
| Кончик | до 10° (в 1.0.0 всё ушко поворачивалось на 3°): кончик проходит примерно в 3,4 раза больше |
| Левое ушко | быстрый взмах наружу ≈ 0,3 с с упругим отскоком внутрь и успокоением; позже снова наружу; короткое подёргивание внутрь |
| Правое ушко | свой рисунок движения: взмах наружу ≈ 0,85 с с отскоком; наклон внутрь в тот момент, когда левое наклоняется наружу; небольшой взмах наружу |
| Между взмахами | едва заметный дрейф (±0,6°), чтобы ушки не замирали |
| Всё ушко | мягкое покачивание из стороны в сторону до ≈ 3,7°: основание на месте, середина наклоняется частично, верхняя часть — полностью; медленная волна (раз за цикл) с небольшой второй волной; правое ушко отстаёт от левого на 0,22 цикла. Изгиб кончика идёт поверх этого покачивания (вместе — не больше ≈ 13°) |

Ушки двигаются независимо, иногда одновременно в разные стороны. Все кривые — плавные периодические сплайны: цикл 3 с бесшовный, скорость на стыке не меняется. Основания ушек не двигаются вовсе (тест проверяет).
