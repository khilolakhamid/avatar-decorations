# Ghost Orbit — анимированная декорация аватара

Версия **1.0.0** · веб-компонент утверждён · TGS не экспортирован (см. `STATUS.md`).

Пять светящихся призраков летят по кругу вокруг фотографии профиля против часовой стрелки, дышат, покачиваются, оглядываются по сторонам и иногда говорят «А-а-а». Декорация рисует только себя, на прозрачном фоне; фото кладёт под неё ваша страница.

- Холст 512 × 512 (`viewBox="0 0 512 512"`), масштабируется целиком до любого размера (проверено: 512, 256, 128, 64).
- Бесконечный цикл 3 с (180 кадров, 60 fps), без скачка на границе.
- Не зависит от фреймворков: обычный JavaScript-модуль, подходит для любого сайта, React, Vue и т. д.
- Зависимостей при работе нет. Векторы встроены в модуль.
- Самостоятельный компонент: не требует других декораций библиотеки.

## Быстрый старт

Готовый модуль — `dist/index.js` (типы — `dist/index.d.ts`). Скопируйте папку `dist/` в проект или установите комплект как пакет (`npm install ./ghost-orbit`), затем:

```html
<div class="avatar" style="position:relative; width:128px; height:128px">
  <img src="photo.jpg" alt=""
       style="position:absolute; left:7.42%; top:7.42%; width:85.16%; height:85.16%;
              border-radius:50%; object-fit:cover">
  <div id="decoration" style="position:absolute; inset:0"></div>
</div>

<script type="module">
  import { mountGhostOrbit } from './dist/index.js';
  mountGhostOrbit(document.getElementById('decoration'), { size: '100%' });
</script>
```

### Место для фотографии

`AVATAR_AREA` = центр (256, 256), радиус 218 в координатах холста 512. То есть круглое фото занимает **85,16 %** ширины декорации и стоит по центру (отступ **7,42 %** слева и сверху). Призраки летят по краю фото и немного над ним. Декорация не перехватывает клики (`pointer-events: none`).

### React (без отдельной зависимости)

```tsx
import { useEffect, useRef } from 'react';
import { mountGhostOrbit } from '@avatar-decorations/ghost-orbit';

export function GhostOrbit({ size = 128 }: { size?: number }) {
  const ref = useRef<HTMLDivElement>(null);
  useEffect(() => {
    const deco = mountGhostOrbit(ref.current!, { size });
    return () => deco.destroy();
  }, [size]);
  return <div ref={ref} style={{ position: 'absolute', inset: 0 }} />;
}
```

## Программный интерфейс

| Что | Описание |
|---|---|
| `mountGhostOrbit(контейнер, параметры?)` | Вставляет декорацию в элемент и возвращает её объект |
| параметр `size` | Число = пиксели, строка = любая CSS-длина. По умолчанию `'100%'` |
| параметр `visible` | Показать сразу. По умолчанию `true` |
| параметр `autoplay` | Начать анимацию сразу. По умолчанию `true` |
| параметр `speed` | Скорость: 1 — обычная. По умолчанию `1` |
| параметр `className` | Класс для корневого `<svg>` |
| `.setSize(size)` | Изменить размер; композиция масштабируется целиком |
| `.show()` / `.hide()` | Показать / скрыть |
| `.play()` / `.pause()` / `.isPlaying` | Анимация |
| `.seek(кадр)` / `.frame` / `.progress` | Показать кадр цикла 0–179 (например, для обложки); текущий кадр; доля цикла 0…1 |
| `.setSpeed(x)` | Скорость: 1 — обычная, 0.25 — замедление |
| `.destroy()` | Остановить и удалить |
| `.element` | Корневой `<svg>` |
| `renderGhostOrbitSvg(префикс?, доля?)` | Статичная разметка SVG строкой, без браузера (сервер, превью) |
| `AVATAR_AREA`, `CANVAS_SIZE`, `FPS`, `FRAME_COUNT`, `LOOP_DURATION_MS` | Константы |
| `GHOST_ORBIT_META` | `id`, название, версия, статусы веб и TGS |

На одной странице можно разместить сколько угодно копий: у каждой свои уникальные `id`, все копии работают независимо.

Для разработчиков (не нужно для обычного подключения): `ORBIT`, `MOTION`, `ghostPose`, `ghostMotion`, `ghostLocalTransforms`, `GHOST_PARTS`, `FACE_IN_GHOST` — расчёты движения, по ним, например, демо показывает одного призрака крупным планом.

## Векторы

| Файл | Что это |
|---|---|
| `ghost` | полупрозрачное светящееся тело призрака: голова справа сверху, волнистый хвост растворяется слева снизу |
| `face` | глаза и рот: 3 отдельных контура (рот, левый глаз, правый глаз) |

Призрак (`ghost` + `face`) описан один раз и используется пятью копиями. Оригинальные SVG не изменены; сборка встраивает их текст байт в байт.

## Анимация

Все движения зависят только от места призрака на орбите. За цикл каждый призрак перелетает ровно на место соседа (72°), поэтому последний кадр совпадает с первым, и стыка не видно. Частоты подобраны так, что соседние призраки никогда не двигаются в такт.

| Что | Движение | Ритм |
|---|---|---|
| Орбита | против часовой стрелки, радиус 188,4 вокруг центра фото; призрак повёрнут по ходу полёта, голова впереди | 72° за 3 с |
| Тело: покачивание | наклон ±4° вокруг центра тела | 2,5 с |
| Тело: дыхание | лёгкое растяжение (+3,5 % по высоте, +2 % по ширине) | 1,875 с |
| Тело: хвост | хвост колышется в стороны с запаздыванием за покачиванием и немного против взгляда; тело мягко вытягивается от головы вниз; голова остаётся на месте | вместе с покачиванием и дыханием |
| Взгляд | прямо → влево → прямо → вправо, с паузами; лицо сдвигается в сторону взгляда, чуть сужается и наклоняется, глаза сдвигаются чуть дальше, дальний глаз уже ближнего, голова чуть клонится туда же (±2°) | 3,75 с |
| Рот «А-а-а» | рот мягко вытягивается вниз и возвращается, глаза чуть вытягиваются | 5 с |

Глаза и рот всё время остаются внутри силуэта тела (проверено замером по всему кругу).
