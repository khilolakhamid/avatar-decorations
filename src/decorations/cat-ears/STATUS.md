# Cat Ears — статус

| | |
|---|---|
| Версия | **1.1.0** (актуальная, `releases/cat-ears/1.1.0/`); предыдущая **1.0.0** доступна без изменений в `releases/cat-ears/1.0.0/` |
| Веб-компонент | 1.0.0 и 1.1.0 **утверждены** владельцем 30.10.2026 |
| Экспорт Telegram TGS | **Не выполнен и не проверен** |
| Изменения | Только по отдельному запросу владельца, с новой версией |

## Что утверждено (1.0.0)

- Два кошачьих ушка из одного оригинального вектора `ear` (правое — как есть, левое — зеркальное) над круглым фото, на прозрачном фоне. Серого круга в декорации нет.
- Цикл 3 с, 60 fps, 180 кадров: оба ушка одновременно и зеркально отклоняются наружу до 3°, возвращаются, чуть уходят внутрь (−1,2°) и возвращаются.

## Что утверждено (1.1.0)

- Ушки изгибаются: основания неподвижны, верхняя часть и кончик шевелятся заметнее (кончик до 10°, примерно в 3,4 раза больше хода, чем в 1.0.0), с упругим отскоком; ушки двигаются независимо. Поверх — мягкое покачивание всего ушка (≈ 3,7°, основание на месте, ушки не в фазе).

## Защита утверждённой версии

`npm test` сверяет отпечатки (SHA-256) итоговой разметки и всех атрибутов анимации во всех 180 кадрах с утверждёнными для 1.1.0. Если тест «approved Cat Ears 1.1.0 is unchanged» падает — значит изменились внешний вид или движение: это требует согласования и новой версии, а не правки отпечатка. Версия 1.0.0 заморожена в `releases/cat-ears/1.0.0/` со своими тестами; `npm test` проверяет, что её файлы не изменились («approved Cat Ears 1.0.0 stays frozen»).

## TGS (Telegram) — заметки на будущее

В 1.0.0 анимация — только поворот двух групп вокруг опорной точки (есть в Lottie/TGS); в 1.1.0 — изгиб контуров с тем же числом точек (морфинг формы, тоже есть в Lottie/TGS). Для экспорта кривую нужно записать ключевыми кадрами. Линейные градиенты, в том числе с прозрачностью, и толстые обводки с градиентом нужно проверить в Telegram. Размер файла не измерен.
