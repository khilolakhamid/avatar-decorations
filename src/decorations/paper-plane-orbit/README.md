# Paper Plane Orbit — анимированная декорация аватара

Версия **1.0.0** · утверждена владельцем 30.10.2026 · TGS не экспортирован (см. `STATUS.md`).

Один бумажный самолётик облетает круглую фотографию профиля с перспективой: появляется маленьким вдали слева, приближается и крупно пролетает перед фото, удаляется вверх вправо, уменьшается и исчезает; невидимым возвращается «за фото» к началу. Декорация рисует только самолётик, на прозрачном фоне; фото кладёт под неё ваша страница.

- Холст 512 × 512 (`viewBox="0 0 512 512"`), как у других декораций; масштабируется целиком.
- Бесконечный цикл 3 с (180 кадров, 60 fps), без скачка на границе.
- Зависимостей при работе нет, вектор встроен в модуль. Самостоятельный компонент: не требует других декораций.

## Подключение

```html
<div class="avatar" style="position:relative; width:128px; height:128px">
  <img src="photo.jpg" alt=""
       style="position:absolute; left:7.42%; top:7.42%; width:85.16%; height:85.16%;
              border-radius:50%; object-fit:cover">
  <div id="decoration" style="position:absolute; inset:0"></div>
</div>

<script type="module">
  import { mountPaperPlaneOrbit } from './dist/index.js';
  mountPaperPlaneOrbit(document.getElementById('decoration'), { size: '100%' });
</script>
```

Место для фото — `AVATAR_AREA`: центр (256, 256), радиус 218, как у остальных декораций.

## Программный интерфейс

Тот же набор, что у других декораций библиотеки: `mountPaperPlaneOrbit(контейнер, { size, visible, autoplay, speed, className })` → объект с `setSize`, `show`/`hide`, `play`/`pause`/`isPlaying`, `seek(кадр 0–179)`/`frame`/`progress`, `setSpeed`, `destroy`, `element`. Статичная разметка без браузера — `renderPaperPlaneOrbitSvg(префикс?, доля?)`. Константы `AVATAR_AREA`, `CANVAS_SIZE`, `FPS`, `FRAME_COUNT`, `LOOP_DURATION_MS`, сведения — `PAPER_PLANE_ORBIT_META`. Для разработчиков: `planeState(доля)` и `planeFrame(доля)` — всё состояние самолётика и все атрибуты рисунка в любой момент.

## Векторы и смена ракурса

| Файл | Ракурс |
|---|---|
| `paper_plane_1` (`Paper_Plane_1.svg`, обновлённая версия) | начало: самолётик маленький, вдали |
| `paper_plane_2` (`Paper_Plane_2.svg`) | середина: крупно, перед фото |
| `paper_plane_3` (`Paper_Plane_3.svg`) | конец: удаляется и исчезает |

Все три файла встроены байт в байт и не перерисованы. Пока самолётик держит ракурс, на экране — сам исходный файл без изменений.

**Переход 1 → 2** (`component/firstTurn.ts`). Обновлённый рисунок 1 сделан на основе рисунка 2: те же 13 элементов в том же порядке, те же цвета, толщины и градиенты (тест сверяет поэлементно). Поэтому переход собирается прямо из элементов файлов: каждая точка каждого элемента едет со своего места на рисунке 1 на своё место на рисунке 2, градиенты едут вместе с ними, мягкие блики (кривые разной формы) не гнутся, а едут со своим крылом и плавно сменяются. Поворот самолётика (~58°) вынесен отдельно, чтобы самолётик не сжимался в середине поворота. Соответствие точек проверено по расположению, а не только по порядку: у хвоста в двух файлах точки записаны в разном порядке, поэтому хвостовые точки сопоставлены по месту, тёмный киль держится стороны хвоста и прикреплён к краю нижнего крыла, а тёмная линия киля (на рисунке 1 спрятана под обводками) проявляется во второй половине поворота. Начало и конец перехода совпадают с оригиналами (разница при сравнении по пикселям — 0,004 и 0,003 из 255), поэтому переход просто встаёт на место оригинала, наложения нет.

**Переход 2 → 3** — как раньше: вершины, градиенты и цвета из двух файлов, блики едут со своим крылом; в первые и последние 10 % поворота поворачивающийся самолётик плавно проявляется / растворяется поверх оригинала, где они совпадают.

На экране всегда один самолётик. Возврат от рисунка 3 к рисунку 1 происходит, пока самолётик невидим.

## Движение

Всё считается из одного числа — прогресса цикла 0…1 (`component/motion.ts`).

| Момент | Что происходит |
|---|---|
| 0–0,45 с | появляется из прозрачности вдали слева, маленький (0,4 → 0,5), рисунок 1 |
| 0,45–1,26 с | приближается и растёт, плавно поворачивается из рисунка 1 в рисунок 2 |
| ≈ 1,38 с | крупно перед фото (размер 1,27), рисунок 2, крен в повороте до 7° |
| 1,5–2,22 с | удаляется вверх вправо и уменьшается, плавно поворачивается в рисунок 3 |
| 2,22–2,64 с | рисунок 3 уменьшается дальше и растворяется у правого верхнего края |
| 2,64–3 с | невидим, возвращается «за фото» к началу (снова рисунок 1) |

Ветер: лёгкое покачивание всего самолётика ±1,45° (3 раза за цикл). Форма самолётика ветром не меняется.
